## 2. FIX-01：消除 M1-旧 的 LOCO 泄漏

### 2.1 病灶（已确认）

`s02_repro_loco.py:63-94`：

```python
M0[k] = median(life(o) for o in keep if same_prog and o != k)   # 对全集算
...
tr = [o for o in sub if o != k]
yv = [life(o)/M0[o] - 1 for o in tr]        # ← M0[o] 里含 life(k)
b  = Σ(x·y)/Σ(x²)                            # ← 斜率被 life(k) 污染
```

**污染路径**：`M0[o]` 是同程序其余刀的中位，含 k → `yv` 含 k → `b` 含 k → 测试折预测含 k。
**污染方向**：`b` 会被拉向"能让 k 拟合得更好"的方向，因此**原 M1 的表现是被高估的**（不管好坏，都是虚的）。

### 2.2 修法：两层留一

```python
for k in test:                        # 外层：留出测试刀
    S = [o for o in same_prog(keep) if o != k]        # 纯训练池
    M0_k = median(L[o] for o in S)                     # 测试用基线
    for o in S:                                        # 内层：训练目标也不能看自己
        M0_o = median(L[p] for p in S if p != o)
    y = [L[o]/M0_o - 1 for o in S]                     # ← 与 k 完全无关
    b = Σ(x·y)/Σ(x²)
    pred_k = (1 + b·rise[k]) · M0_k
```

要点：
1. **`M0` 变成折内变量**，不再是全集常量；
2. 训练目标用**内层留一**基线（严格版）；同时保留一个"仅去 k、不做内层"的版本作对照，用于量化内层留一带来的差异；
3. `M0-B` 与 `M1-new` 同样检查：`s03` 的 `pool` 已排除 k（无测试泄漏），但 `lr = log((L[o]-N)/m0b)` 里的 `m0b` 含 o 自身 → 属**样本内自归一**，一并改为内层留一；
4. **不改字段名掩盖**，新增列显式标注：`M0_Source`, `InnerLoo=True/False`。

## 3. FIX-02：构建真正因果的 `as_of_N` 单件 HI

### 3.1 病灶（已确认）

现行离线 `cmd_xalign`（`t1111_pipeline.py:1199-1256`）为每个周期一次性算出：

| 参数 | 现状算法 | 用到的未来信息 |
|---|---|---|
| `z0` | 全周期 `speed>0` 行的 `round(z,1)` 众数 | 整段周期 |
| `cap_ref` | 全周期最大转速 | 整段周期 |
| `glo/ghi` | `linspace(p90(x_lo), p10(x_hi))` | **全部件**的端点分位 |
| 覆盖率掩码 | `mean(finite) ≥ 0.70` | **全部件** |
| 基线 `base` | 前 10 件各格点中位 | 前 10 件（这一项本身是因果的） |

→ 所以"截断到前 N 件"只截断了**取值**，HI 的**构造**仍看过未来。

### 3.2 修法：`as_of_N` 管道（逐 N 重建）

```text
对每个 (life, N):
  取该周期前 N 件的全部原始行（严禁读第 N+1 行及以后）
  1) z0_N     = 前 10 件内 speed>0 行的 round(z,1) 众数
  2) cap_ref_N= 前 10 件内最大转速（drop_cap=False，本项实际不生效，仍按因果口径保留）
  3) 逐件 _xalign_piece(g, z0_N, ...) → x_lo/x_hi
  4) grid_N   = linspace(p90(x_lo[1..N]), p10(x_hi[1..N]), 40)
  5) M[N×40]，覆盖率掩码只用前 N 件
  6) 逐格点 base = median(M[1..min(10,N)])；HI_i = 件内中位(M_i / base)
```

**关键约束**：`grid_N` 会随 N 变化 → `HI_asof_20` 与 `HI_asof_80` **不是同一条曲线的截断**，而是两条独立曲线。这正是审核要的"as_of"语义，必须接受。

**备选（更严格）**：把 `grid` 冻结为**与测试刀无关的固定物理区间**（19.0~40.0 或由训练集确定的模板），彻底消除"网格随刀变"。两种都做，并列报告：
- `Mode-C1` 自观测网格（`grid_N` 随 N）
- `Mode-C2` 冻结模板网格（全周期恒为常数，参数来自训练折）

## 11. 执行顺序（四批，每批之间可评审）

```text
第 1 批（方法论，最高优先）    FIX-01 + TEST-A       → 只改 M1
                              FIX-02 + TEST-B       → 改全部 HI
                              FIX-07                → 用新 HI/新 M1 重算对比
         ↑ 此批完成后，历史 MAE 全部作废并替换；请在此暂停评审

第 2 批（数据身份）            FIX-03 + TEST-C       → 样本集 A/B
                              FIX-06                → 网格矛盾结案
         ↑ 此批决定"到底有几个可信生命周期"

第 3 批（崩刃 A）              FIX-05                → 因果 + 行级
                              FIX-06 的 latency     → 延迟预算

第 4 批（交付与前端）          FIX-04 + FIX-08 + GOV-01
```

**为什么这样排**：FIX-01/02 会改所有数字，必须最前；FIX-03 会改样本，必须在其后；崩刃 A 依赖 FIX-02 的因果口径；交付放最后，避免重复打包。

## 14. 一句话总结

**这轮整改的核心不是"把数调好看"，而是把三个"看起来严格其实不严格"的地方补上：留一没留干净（FIX-01）、截断没截构造（FIX-02）、样本没按物理刃口分（FIX-03）。**
