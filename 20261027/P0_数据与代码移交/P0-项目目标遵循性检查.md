## 本轮 1 号位主动承诺（写死）

1. **不**把项目一改口径为"固定件数换刀提醒 / 安全延寿许可 / 仅提前换刀二分类"；
2. **不**把项目二 A 改成"事后报表 / 单件完成后报警 / 人工发现后登记"；
3. **不**把项目二 B 升级为必达、不与 A 混算；
4. **不**因某模型负结果宣布项目停止或某路线"永久不可行"；
5. **不**把"未批准采购"当"技术路线永久关闭"；也不凭负结果要求直接采购；
6. **不**把 4152/T1111 水性结论直接外推到 2496/T2525、2428/T3434 或油性目标机床；
7. **不**自行把本任务书 §0 视为冻结裁决（本任务书已是 0 号位最新明确口径，但仍属研究授权 ≠ 采购授权 ≠ 生产应用授权）；
8. **不**要求生产人员改变现有报工/换刀业务流程（D04 只提表单，等 0 号位/车间确认后再动）。
