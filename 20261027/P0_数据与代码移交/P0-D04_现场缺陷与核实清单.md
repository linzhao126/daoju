## 3. 建议现场最小新增字段（不改动现有报工流程，只加填空）

| 场景 | 必填 | 单位/取值 |
|---|---|---|
| **正常换刀**（每把刀） | 机床 ID / 刀位或刃口 ID / 上刀动作时刻 / 下刀动作时刻 / 发生时 `allnum` 或当班工单标识 / 实际终止原因（正常磨损·崩刃·尺寸或质量超限·预防换刀·其他） / 是否更换了物理刀片 | 时刻到分钟足够；`allnum` 抄页面 |
| **异常发现**（崩刃 / 质量异常） | 首次发现时间 / 最后确认正常时刻 / 可疑受影响产品范围 | 三时刻缺一不可，允许 `UNKNOWN` 但不能缺栏 |
| **跨班 / 维修 / 试切**（G-5 需要） | 起止时刻 / 类别 | 用于区分"停机"与"采集失败" |
| **可选增强**（不强制） | 刀片损伤照片 / VB 值 / MES 工单号 | 有则附，无不影响基础研究 |
