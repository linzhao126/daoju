## 一、一行代表什么

一行 = 一个 **(口径 Tag × 模型 × 截断件数 N × 测试刃口)** 四元组合。

| 维度 | 取值 |
|---|---|
| 口径 | `L26_eval_L26`（宽松训练+宽松评估）· `S8_eval_L26`（严格训练+宽松评估）· `S8_eval_S8`（严格训练+严格评估） |
| 模型 | `M0A` 历史中位数 · `M0B` 条件生存 · `M1Old` / `M1New` HI 修正（旧/新程序归属） |
| 截断件数 | 20 / 40 / 60 / 80 |
| 测试刃口 | 26 个（`4152-L-T1111-cXX`） |

**568 行有预测 + 42 行"算不出"**（不是留空，而是带 `失败原因`）。

## 二、任务书十项要求 → 列映射

| 要求 | 本表列 |
|---|---|
| 训练池ID | `训练池ID`（逗号分隔刃口列表）+ `训练刀数` |
| 测试刃口ID | `测试刃口ID` + `台账顺序号` + `程序` |
| **截至该时点的输入** | `输入_已用件数` / `输入_已用寿命占比` / `输入_HI_comb当前件` / `输入_HI_comb累计均值`（从 `HI_merged_28.csv` 按 `piece_idx ≤ N` 回捞） |

| 误差 | `绝对误差`（对 `真实剩余ActualRUL`） |
| 失败原因 | `状态=算不出` 行的 `失败原因`（如"同程序且寿命>N 的训练刀只有 1 把 < min_fit=2"） |

| 实验 Commit | **三列区分**：`预测来源Commit` / `输入数据Commit` / `装配Commit` |
| 时间 | `生成时间` |

## 五、已知局限（不掩盖）

1. **`输入_HI_comb*` 只对 M1 两个模型有意义**：`M0A`/`M0B` 是纯统计基线，只消费"已用件数 + 训练池寿命分布"，**不看 HI**。填在同一行上是为了便于逐行核对"该时刻谁能看到什么"，不代表 M0 用了 HI。
2. 区间列只有 `M0B` 与 M1 有（`PI_lo/PI_hi`）；M0A 无区间，`落入区间` 记"无区间"。
3. `实际终止类型` 全部来自台账文字（**未独立核实**）；能进正式真值评分的只有 **9 把**（见 `P0-D05`），其余行的预测误差不应作为验收依据。
4. 本表**不重造模型**：预测值全部复用 s53 已交付产物，脚本只做"拆长 + 回捞输入 + 挂等级 + 记 commit"。若要新模型（审核方 M2），应在同一张表的列结构下另出一份，便于逐行对比。
