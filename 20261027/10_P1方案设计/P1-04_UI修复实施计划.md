## 四、回滚方案

- 全部改动集中在 `server.py` / `index.html` 两个文件；
- 保留当前两份文件的 SHA256（`01_.../MANIFEST.csv` 中 `02_源代码与配置/source/server.py`、`index.html`）；
- 回滚 = 用交付包里的 `source/` 覆盖回去，**不需要动数据库**；
- 唯一涉及数据库的是 D6 的 `src` 字段：`ALTER TABLE history ADD COLUMN src TEXT DEFAULT 'online'` 是**可逆的**（不用可忽略），但**迁移后旧行会被默认成 online** —— 所以必须先用 `UPDATE` 把现有 16 条置为 `seed`，再改默认值。
