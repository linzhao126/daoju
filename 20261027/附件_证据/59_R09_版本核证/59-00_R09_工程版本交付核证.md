## §2　运行版本探针（`R09_runtime_probe.json`）

### 2.1 怎么做到"不停真实机"

| 项 | 做法 |
|---|---|
| 代码 | 复制 `server.py` / `index.html` / `simulator.py` / `influx_source.py` 到 **temp 目录** |
| 数据库 | 复制 `03_原始数据与标签/tool_db_snapshot/tool.db.readonly_copy` → `temp/data/tool.db` |
| 数据源 | `--source sim`（**不走 influx**，不向外拉数据） |
| 端口 | 18765（避开线上的 8765） |
| 代理 | 代码内 `ProxyHandler({})`，绕过 `HTTP_PROXY`——否则 127.0.0.1 被劫持会返回假 502 |
| 收尾 | 进程 terminate、temp 目录删除（`R09_KEEP=1` 可保留） |

**生产库 `data/tool.db` 全程未被打开。** 副本库测前/测后 SHA 相同（`3fd701389c45`），连 sim 写入都没落盘（sim 无数据源时不产行）。

### 2.2 实测输出

```
HTTP 200  ok=True
code_sha（运行中）= f336f1d673e0 ；磁盘文件 sha256 前 12 位 = f336f1d673e0 → 一致
policy_mode=MONITOR_ONLY  safety_permit=False  judge_allowed=False  base_src=cold  used=100
reference_rule=COUNT_H  ref_limit_90=None（0.9xM0）  ref_limit_40=None（D-05）
exposure_by_segment=[{'seg':1,'prog':17,'pieces':45}, {'seg':2,'prog':16,'pieces':55}]（合计 100）
段数=2  物理ID=phys_T1111_61166
页面 index.html 取回 26684 字节
副本库 SHA 前后：3fd701389c45 → 3fd701389c45
```

> ⚠ `ref_limit_90=None` 是**预期**：快照的起点未确认（`judge_allowed=False`）→ 按 P0-MOD-04 连参考线也不给。
> 起点确认后该字段会等于 `ceil(0.9×M0)`。

**这五行同时证明了三件事**：
- **R03 生效**：`exposure_by_segment` 在**真实快照数据**上给出两段（prog 17 的 45 件 + prog 16 的 55 件），合计 = `used` = 100。这就是"同一把刀跨程序"的现场实例。
- **P0-MOD-04 生效**：快照里 `tool_events` 0 行 → `base_src=cold` → `judge_allowed=False`（不给判定）。
- **P0-MOD-01 生效**：`safety_permit=False`、`policy_mode=MONITOR_ONLY`。

⚠ **页面渲染仍不是"浏览器回归"**：这里只证明了"HTTP 能返回 200 + 页面能取回字节"，**没有**用无头浏览器跑 JS、没有点按钮、没有核对 CSS。`45-00` 里"渲染回归未做"这条**仍然成立**，只是把"接口层没验证"补上了。
