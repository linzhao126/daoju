## 二、⭐ 核心修正：分辨率够 ≠ 能分档

### 2.1 旧的推理链（2026-09 月）

```text
磨损信号只有 3%
伺服负载台阶 0.56%
→ 3% / 0.56% = 5.4 个台阶
→ 刻度层面"够分 5 档"
→ 所以瓶颈是台阶？  ← 这里断了
```

**前四步都对，第五步错。** 因为"能分档"靠的**不是刻度分辨率，是重复测量的稳定性**。

### 2.2 正确的推理链（2026-10-16 实测）

T1111 相位对齐后的实测统计量（17 个周期，逐周期见 `E05`）：

| 量 | 数值 | 来源 |
|---|---|---|
| **全寿命信号幅度 A** | **中位 2.47%**（范围 0.49%~8.88%） | 逐周期斜率 × 件数 |
| **单件噪声 σ** | **中位 1.95%**（范围 1.42%~2.73%） | 去趋势残差标准差 |
| **寿命 T** | **中位 97 件** | — |
| **5 档档间距** | A/5 = **0.49%** | — |
| **σ / 档间距** | **4.0 倍** | — |
| **±3σ** | **±5.9%** | **> 全寿命信号 2.47%** |

### 2.3 这句话是关键

> **一次测量的 ±3σ 波动跨度（±5.9%）比整个寿命的信号幅度（2.47%）还大。
> 换句话说：同一把刀在同一个磨损水平的两次测量，差值可以覆盖全部 5 个档。**

这不是"刻度不够细"，是"尺子刻度够了，但读数在抖"。

### 2.5 ⛔ 由此撤回的旧表述

| 旧说法 | 判定 | 修正后 |
|---|---|---|
| "P0 的核心目的是**提高分辨率**，瓶颈是量化台阶" | **`WITHDRAWN`** | **P0 的核心目的是「降噪」**。主力通道分辨率 0.1% 早就够，瓶颈是单件噪声 1.95% |
| "DTRQ 预计噪声 0.56%，否则 C3 永不可能" | **`WITHDRAWN`**（主包 `07-2 §5` 已做） | 0.56% 是 `L_X_servo_load` 的**台阶**，与 DTRQ 实测噪声无关 |
| "Z 伺服只有 3/4/5 三个值" | **需限定数据集** | 20260914 是 {3,4,5}；20261012 是 {1,3,4}。**都是 3 个主台阶** |

**正确的 P0 表述**：

> **"现有主轴负载通道的磨损信号约 2.47%，单件噪声约 1.95%，
> 信噪比 1.2~1.6，5 档要求信噪比 ≥ 3（σ≤0.556% 或 T≥1198 件）。
> 扭矩类通道（DTRQ/TCMD/ERR）的价值在于**剔除摩擦/热漂/惯性，把 σ 降下来**，
> 而不是提高刻度分辨率。是否真能降，需实测。"**

## 四、为什么"综合多指标"会变差（本文解释主包未解释的一点）

主包 `P0-04` 只用了 3 个预定义特征，没解释为什么不多用通道。实测答案：

| 通道 | r（prog11 队列） | 对综合 HI 的贡献 |
|---|---|---|
| **`L_spindle_load`** | **+0.291** | 唯一正贡献 |
| `L_X_servo_load` | **−0.232** | **强负贡献** |
| `L_Y_servo_load` | +0.132 | 微弱正 |
| `L_Z_servo_load` | +0.078 | 近零 |
| `L_spindle_speed` | +0.014 | 零 |
| **等权综合 HI** | **+0.042** | **互相抵消** |

（prog14：+0.264 → **−0.006**；prog20：+0.076 → **−0.074**）

### 4.1 机制

```text
HI_综合 = (+0.291 信号 + (−0.232) 反向 + 0.132 + 0.078 + 0.014) / 5  ≈ 0.06
```

**1 个强正 + 1 个强负 + 3 个接近零 = 归零。**

> **铁律**：等权平均只在"各通道同向且强度相近"时有降噪收益。
> 本项目是"1 强正 + 1 强负 + 3 个零"，平均就是自杀。

### 4.2 一条可操作的特征筛查规则

```text
1) 离散取值 ≤3 个 → 直接删（A_servo_load 只有 0/1/2）
2) 基线近零（前 10 件中位≈0）→ 直接删（B/C/E）
3) 队列级 r 与主通道反号 → 不参与平均（X_servo_load）
4) 剩下的一两个通道 → 单独用，不平均
```

## 六、不能由本文推出

| 不能推 | 原因 |
|---|---|
| "扭矩通道噪声一定更低" | **完全没测过**。σ=1.95% 是主轴负载的，DTRQ 的未知 |
| "降噪到 0.556% 就能做 5 档" | 那是数学必要条件（`11-05 §三`），还要求"信号方向稳定"，而 6/17 周期反向 |
| "Z 伺服分辨率 20~33% 所以完全没用" | 它做**工步识别**（`R_rate1`/负载分档）仍有用；只是不能做**磨损量** |
| "主轴负载分辨率 0.1% 精确到 0.1%" | 那是刻度；实际读数被噪声主导，**有效精度 ≈ 2%** |

## 七、一句话

**旧 P0 说"我们采得太粗"，实测打脸：主轴负载刻度 0.1%，早就够。
真正的问题是"读数在抖"——单件噪声 1.95%，一次测量的 ±3σ 比整个寿命的信号还大。
所以不该去找更细的尺子，该去找更安静的量。**
