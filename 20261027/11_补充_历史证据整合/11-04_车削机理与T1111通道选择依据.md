## 〇、三句话

1. **选哪个通道不是试出来的，是算出来的**：Fz 占 100% 走主轴负载；Fx 占 15~25% 走进给轴；Fy 占 30~50% 走非进给轴。
2. **T1111 的进给轴是 X**，所以 X 伺服只承载最小的 Fx + 量程大 → **只有 3 个主台阶是力学必然，不是采集盒的错**。
3. **车削有一条铣削没有的免费通道：磨损 1:1 变成尺寸漂移。** 力只涨 2.47%，尺寸却变 0.3 mm。

## 一、三向力分解（选通道的依据）

车削切削力标准分解（钢件、主偏角 45°~90°）：

| 分量 | 方向 | 相对大小 | 由哪个通道承载 |
|---|---|---|---|
| **主切削力 Fz** | 切向（旋转方向） | **100%** | **主轴负载**（吃掉约 90% 切削功率） |
| **进给力 Fx** | 沿进给方向 | 15 ~ 25% | 进给轴的伺服负载 |
| **背向力 Fy** | 径向（压向工件） | 30 ~ 50% | **非进给轴**的伺服负载 |

经验公式（钢 σb ≈ 0.735 GPa）：**Fz ≈ 2000 · ap · f^0.75**（N；ap 单位 mm，f 单位 mm/rev）

### 1.1 对 T1111 的直接推论

T1111 是**切断刀**，切断是**径向进给 → 进给轴 = X**。

```text
X 伺服承载的只有 Fx = 15~25%（三个分量里最小）
且 X 轴量程最大（0~180）、台阶最粗
→ L_X_servo_load 只有 3 个主台阶，是力学 + 量程的必然结果
→ 主通道必须是 L_spindle_load（Fz，100%）
```

**这条与 `11-02` 的通道排序完全一致。**

### 1.2 ⭐ 一个历史疑问，这里可以闭环了

`E04` 曾列出一个待澄清问题：

> "T1111 的 xalign 用的是哪个通道？**若一直在分析 X 轴伺服负载（3/4/5 三档），
> 说明在最弱的通道上努力，应改主轴负载。**"

**答案（见 `11-01`）**：xalign 输出的 HI 是 `HI_L_spindle_load` —— **用的就是主轴负载**，
不是 X 伺服。所以这条隐患**不存在**，方法用对了通道。

侧证：`11-01 §二` 里 X 伺服在 prog11 队列的 r = **−0.232（反号）**，
而主轴负载 r = **+0.291** —— 如果当年用了 X 伺服，会得到负相关，直接判"无信号"。

## 二、G96 恒线速度：为什么会有"纯几何"的大幅漂移

T1111 的切断工序跑 **G96 恒线速度**：

```text
v 恒定  →  转速 n ∝ 1/D
主轴扭矩 T = F · D/2 ∝ D
```

即：**直径变小 → 扭矩变小**。这是**纯几何效应**，与刀具磨损无关，但幅度远大于磨损。

**这正是 X 相位对齐要消掉的东西**：把每件重采样到同一 X 网格（18.8~40.0 mm，
见 `11-01 §二`），几何项就被约掉了。

> 主包 `§4.1` 发现"线上 `X_MIN=19` 可能砍掉了尾段"——若成立，
> 在物理上就是**砍掉了 G96 效应最强的尾段**。
> ⚠ 但该结论与 `E01` 的网格记录冲突，**已列为 `UNRESOLVED`，见 `11-01 §六`**。

### 2.1 一个仍未搞清的关键点（影响归一化口径）

> **主轴负载表显示的是"额定扭矩百分比"还是"额定功率百分比"？**

主轴电机在**基速以下恒转矩、基速以上恒功率**。
这直接决定 G96 下负载% 如何随转速变化，进而决定归一化该怎么做。
**必须问机床厂/供应商**（与 `07 G2` 同级的一句话缺口）。

### 2.2 G99 每转进给的连带影响

`L_rate1` 变化 → 实际进给速率 `mm/min = f × n` 变化。
这是工步识别的基础，也意味着**涉及时必须按转频归一化**。

## 三、相位对齐：T1111 上确实有效（复述关键结论）

| 项 | 值 |
|---|---|
| 对齐轴 | **X**（切断的径向进给；Z 全程锁定） |
| 网格 | 起点 **18.79 ~ 19.18 mm**，止点 **40.00 mm**，插值 40 点 |
| 基线 | 本周期**前 10 件**（`base_k=10`） |
| **prog11 队列 r** | **+0.291（p=2.4e-06，n=253）** |
| **prog14 队列 r** | **+0.264（p=1.9e-10，n=563）** |
| prog20 队列 r | +0.076（p=0.056，**不显著**） |
| 逐周期 17 个 | **11 正 / 6 负**（符号检验 p≈0.33） |
| 综合多指标 HI | **+0.042 / −0.006 / −0.074（全面失败）** |

**详细论证与逐周期表见 `11-01`，分档天花板见 `11-05`。**

### 3.1 对齐方法的前提（迁移时必须先检查）

> **相位对齐不是通用方法，它的前提是"该工序的进给轴在件内有足够行程"。**

- T1111 切断：X 从 **18.8 扫到 40.0 mm**（跨 21 mm）→ **有空间，可对齐**；
- 若换成"径向进给行程很短"的工序（例如只进 2~3 mm 的精加工），
  件内可用点太少 → 对齐失效，只能退回**工步门控 + 分段平均**。

**这条支撑主包 `P1-05 §三` 的迁移校验清单第 3 项**（对齐覆盖率 ≥80%）：
在行程不足的工序上，这一项永远过不了 → 只能做 C0 监控，不能做 C2 判定。

## 四、⭐ 车削独有优势：磨损 1:1 变成尺寸漂移（免费监督通道）

### 4.1 机理

车削是**单点刀**。后刀面磨损 VB → 刀尖后退 → 加工直径变大：

```text
尺寸漂移 ≈ 磨损量，1 : 1
```

对比切削力：**力只涨 2.47%，尺寸却变 0.3 mm。放大倍数差两个数量级。**

铣削没有这个性质（多刃、断续切削，只能间接看表面粗糙度/毛刺）。

### 4.2 两条可落地的免费通道

| 通道 | 内容 | 价值 |
|---|---|---|
| **① 刀补（wear offset）调整记录** | 每次调整量 ≈ 该区间磨损量；调整间隔 ≈ 磨损到超差的时间 | 既是**近似 VB 真值**，又直接给出**磨损速率** |
| **② 抽检尺寸 / SPC 记录** | 若已数字化 | 序列 = "带噪声的磨损积分曲线"，灵敏度**远高于任何负载通道** |

### 4.3 ⚠ 一个必须注意的实测限制

`L_wear_x` 在周期内**基本恒定**（人工阶梯调整）：
实测 min 0 / max 0.6，且**多数周期只有 1~2 个不同取值**。

**所以不能用它的绝对值当磨损量**，但**调整事件的发生时刻**是信号：

```text
正确用法：把「刀补被调整了一次」当作一个事件，看事件间隔 → 磨损速率
错误用法：把 L_wear_x 的当前值当作当前磨损量
```

### 4.4 优先级判断（本文对主包最有价值的一条）

主包 `07 G5` 把"尺寸/粗糙度记录"列为**二级缺口**（成本中）。本文主张**提升到一级**：

| 对比项 | 买 USB 显微镜测 VB | 取刀补/SPC 记录 |
|---|---|---|
| 成本 | 200~500 元 + 人工逐刃测量 | **0 元**（数据可能已在产生） |
| 分辨率 | 0.001 mm | 取决于抽检频次 |
| 覆盖 | 只能抽样 | **全批次连续** |
| 时效 | 事后 | **可在线** |
| 与 RUL 是否同源 | 是 | **是（1:1）** |

> **"取现场已有的数字"应该排在"买新设备"之前。**
> 这不是理论：主包 `06 §五` 实测换刀前后负载只差 −2.5%~+7.4%（与件间噪声同级），
> **而尺寸记录对同一件事的分辨力是 0.3 mm 级。**

## 五、门控消不掉的那部分噪声：毛坯余量公差

### 5.1 问题

切削力 `F ∝ ap`（切深）。**毛坯余量公差直接变成力波动**，与刀具无关。

**关键**：对齐和门控都消不掉它——它们只处理"几何位置"和"动作类型"，不管"这一刀切了多深"。
这解释了为什么 T1111 相位对齐后仍有 **σ ≈ 1.95%** 的件间噪声（而不是接近 0）。

### 5.2 对策

`L_abso_x`（或 `R_abso_x`，视通道）已确认 **100% 非空** → 用坐标反推每件的实际 `ap`，
作为**协变量**回归掉（或按 `ap` 分层）。

**这是目前最具体、最可执行的车削专属改进**，零硬件成本。

### 5.3 一个待问现场的数

> **毛坯余量公差是多少？**

它决定 `ap` 的波动幅度，也就决定了"还有多少噪声是可以通过反推 `ap` 消掉的"。
若公差本就很小（±0.05 mm），这条改进的收益有限；若达 ±0.3 mm，可能是主要噪声源。

## 六、外部参照：无传感器路线的理论天花板

### 6.1 PHM2010 与 T1111 的差距

| 项 | PHM2010 | T1111 |
|---|---|---|
| 采样率 | **50 kHz** | 62.5 Hz（16 ms 上报） |
| 硬件 | Kistler 三向测力仪 + 3 加速度计 + AE + NI 采集卡 | 无，只读数控内部变量 |
| 通道 | 7 个（Fx/Fy/Fz + Ax/Ay/Az + AE-RMS） | 内部变量，被动接受 |
| 标签真值 | **显微镜逐刃实测 VB（0.001 mm）** | 人工换刀时刻，VB 不可得 |
| 工况 | 恒定 10400 rpm / 1555 mm/min / 切深固定 | 多程序、件内混工步、转速会切 |
| 样本 | 3 把刀 × 315 次走刀 × 20 万点/次 | 21 个周期 / 1,614 件 |

**采样率差约 800 倍，标签精度差 3 个数量级，工况复杂度还更高。**

### 6.2 天花板判断

> **无传感器路线只能做「严重磨损阶段分类（2~3 档）」和「异常状态确认」，
> 做不到「定量 RUL 回归」和「5 档以上细分」。**

这不是悲观，是量级比较的结果：PHM2010 用 50 kHz + 0.001 mm 真值 + **恒定工况**，
做 RUL 回归都只是"挑战赛数据集"级别；我们在 62.5 Hz + 无真值 + 变工况下做同一件事，
差距不在算法。

### 6.3 一个反直觉但重要的推论

**别去铣削的 TCM 论文里找方法。**

- 铣削有**齿通频率**作为冲击载波 → 包络谱 / AE / ACZF 灵敏；
- 车削是**连续切削、无载波**，磨损只能表现为**缓慢漂移**（约 2.47%），
  还被恒转速环吃掉 → **r≈0.29 是车削在现有通道下的固有水平，不是算法没调好。**

## 七、对主包 `07-2 §4` 的处置建议

主包把"恒转速把负载信号搬到扭矩通道，我们只是在读车速表"判为
`UNVERIFIED → HYPOTHESIS`，理由是"缺 FANUC 字段级读数定义与对照实测"。

**本文支持这个降级，但要补一句**：

> 这个机理**有旁证但无直证**。
> **旁证**：① 同程序同工况负载差异 <5%（控制回路在维持恒定）；
> ② 主轴负载 r 只有 0.29（若磨损直接体现在负载上，应该更高）；
> ③ 力分解显示 Fz 走主轴扭矩（§一）。
> **直证缺口**：**主轴负载表是扭矩% 还是功率%** 未确认（§2.1）；
> **没有 DTRQ 读数**，无法证明"信号确实躺在扭矩里"。

**因此正确表述是**：

> "控制回路很可能把磨损的力增量转成维持转速所需的扭矩增量；
> 我们读的是被控量（转速/负载%），不是控制量（扭矩）。
> 这一点有力学依据，但**'扭矩通道里确实有可用信号'尚未实测**。"

## 八、一句话

**车削的磨损本就只体现在两处：力的 2.47%（被恒转速环搬进了扭矩，我们没读），
和 1:1 放大的尺寸漂移（0.3 mm，我们没采）。
两处都没读，然后说"信号不存在"——这才是真实处境。
而这两件事里，**尺寸漂移是零成本的，应该先做**。**
