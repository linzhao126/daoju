## 2. 逐步退出码

`step()` 用 `set +e; "$@"; rc=$?; set -e` 捕获**真实 exit** 并回显 `[exit=$rc] 步骤名`；
非 0 立即中止并把该码向上传递（不再是统一吞成 `exit 1`）。CI 里 `bash run_all.sh` 的
返回码即为失败步骤的原始退出码；`V01 判据机检(s46)`、各测试件失败都会硬阻断。
