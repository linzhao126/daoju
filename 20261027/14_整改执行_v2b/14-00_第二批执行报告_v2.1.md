## 3. FIX-05：崩刃 A 因果重构（负结果）

### 3.1 对治三条病灶

| 病灶 | v1 | v2 |
|---|---|---|
| 健康段用最终寿命 `n` | `nh = max(20, n×0.25)` | **模板固定前 10 件**（先验常数） |
| 持续性靠 CUSUM>0 累积 | 延展到 CUSUM 归零 | **连续 3 个 z 同号且 >0.3** + CUSUM>5 + 冷却 20 件 |
| 件级三个标量 | med / peak / cv | **件内 40 点相位残差**（逐网格点减模板，取中位绝对偏离） |

### 3.2 结果

| 指标 | 数值 |
|---|---|
| 弱标签异常候选覆盖率（破损） | **11/11 = 100%** |
| 磨损对照周期也报警比例 | **2/2 = 100%** |
| 误报密度 | 0.18 次/切削小时；28.9 次/千件 |
| 首次候选位置 | 寿命的 **3.7% ~ 44.9%** |
| ≤1 秒检出 | **NOT_REPORTED** |

### 3.3 结论

**特异性为零，不可用。** 百分百的"覆盖率"没有任何意义，因为对照周期同样百分百报警。

根因（本轮新增证据）：
- 同一 X 上有两个工步，负载双峰（中位 1606 / p90 5286）→ 不先做 X/Z 相位对齐，残差被工步差异淹没（第一版阈值被顶到 6000+，全周期零事件）；
- 做了相位对齐后，**磨损周期（c38）的末期抬升 1.37 倍，与破损周期（c26 1.46、c25 1.21）同量级** → 相位残差对"破损"没有特异性；
- 这与上一轮"换刀前后负载只降 0~7%"的结论一致：**主轴负载对刃口状态的敏感度本身就低**。

**下一步（诚实结论）**：件级（哪怕是 40 点相位）不可能满足 A 目标。真要做 A，只有两条路：
① 真·行级 + 边缘推理（需 `recv_ts` + 实时链路）；
② 振动/高频通道（需硬件，且属油性切削液机床立项）。
